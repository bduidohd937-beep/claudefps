## 우선 처리해야 할 버그 (다음 패치 후보)
1. 권총 일부만 보이는 현상 — GLB 스켈레톤·애니메이션·스킨 메시의 실제 트랜스폼 분석 후 수정. 슬라이더만으로 해결된다고 가정 금지
2. 나이프 과대 표시 — 무기별 화면 기준 크기 및 FOV/팔 위치 검증
3. 라운드 사망 이후 탄창/예비탄약 정상 초기화 여부 재현·수정 (라운드 생존/사망 규칙 명시)
4. 달리는 중 탄피가 사격 없이 계속 배출되는 현상 — 실제 발사 이벤트에만 연결
5. 일부 맵 스폰 추락·벽 끼임 — 실제 GLB 바닥 콜라이더 기준 재검증, F6 편집 UX 정비

## UX · 시스템 개편 후보 (후속 임시기획)
- 별도의 메인 화면: 플레이 시작, 맵 선택, AI 난이도, 무기·조준선·사운드·감도 설정
- 조준선 설정: 점 / 십자 / 가변 퍼짐 크로스헤어 및 색상·크기·간격
- 총기별 발사·장전 사운드 교체, 볼륨과 중복 재생 방지
- F6 스폰 편집: 3D 마커, 좌표 범위 시각화, 안전 지면 자동 추천, 플레이어·AI 스폰 미리보기
- 설정 UI 분류: 조작, 그래픽, 오디오, 게임플레이, 개발 도구
- 5선승 1:1 고유 라운드 경제 및 구입 시간 검사

## AI 개선 연구 후보
- 난이도를 단순 헤드샷 확률이 아니라 반응 지연, 조준 오차, 추적 보정, 이동 패턴, 엄폐 선택 등으로 분리
- 원거리 헤드샷 과도 빈도 제한 및 시야/거리별 반응속도 보정
- 소리 인지: 사격/발소리 이벤트 → 마지막으로 들은 위치 추정 → 확인 이동 (벽 뒤에서 즉시 정확히 알지 못하게)
- 메모리/시야: 마지막 관측 위치, 반응시간, 짧은 탐색, 에임 흔들림, 엄폐와 브레이킹 구현
- 5개 난이도별 실제 플레이 밸런스 테스트

원칙: 기존 안정화 코드는 보존, 매 패치 별도 브랜치 및 실제 검증 여부 명시.
