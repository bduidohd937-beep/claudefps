# FPS V0.2.9 — WEAPON & COMBAT PACK

## 구현 상태
GitHub 기능 브랜치의 코드 변경은 반영했다. 빌드·브라우저 실전 플레이는 아직 검증되지 않았다.

## 신규 플레이 가능 총기 (신규 GLB 미보유 → 직접 만든 임시 3D 모델)
- M4A1 ($2900) — 반동 낮은 주무기
- MP5 ($1750) — 고연사 기관단총
- 펌프 샷건 ($1600) — 독립 산탄 8발 판정
- AWP ($4300) — 5발 장전의 저격형 소총 (조준경/ADS 미구현)
- Desert Eagle ($900) — 7발 장전의 고화력 보조무기

기존 AKS-74u, Glock, 나이프는 기존 GLB를 유지한다.

## 변경사항
- 새 무기별 데미지·거리감쇄·사격간격·반동·탄창·예비탄약·장전시간 정의
- 주무기/보조무기 별 구매·교체·장착 구현, 1=주무기, 2=보조무기, 3=나이프
- AI는 이후 라운드에서 돈이 부족하면 MP5를 구매할 수 있음
- 점/고정 십자/가변 십자 조준선과 컬러 설정을 로비 및 일시정지에서 저장
- 원본 AK GLB 'Fire_sprite'를 달리기 애니메이션으로 호출하지 않음 (달리며 탄피 나오는 연출의 원인 후보)
- 플레이어·AI 총구 화염 메쉬 크기·불투명도·지속시간 감소
- 신규 무기마다 독립적인 Web Audio 합성 발사음 (외부 MP3 교체는 후속)
- 적 양 어깨에 오렌지 포인트 식별 표시 (벽 뒤 표시하지 않음)
- F2 튜너에 새 무기 포함, 자동화 회귀 테스트 5개 추가

## 남은 구현/검증
- 실제 GLB 5종 수급 후 각 무기 애니메이션과 보정값 교체
- AWP 조준경, 스프린트/장전 애니메이션, 개별 총성 오디오 자산 교체
- AI의 모든 신규 총기 구매·전술 선택 (현재 AK와 저가 MP5 우선)
- 총구 화염 위치가 실제 총구와 정렬되는지 실전 확인
- 8종 무기 피격·발사·탄창·상점·데스 후 분실·라운드 초기화 테스트
- 엔진 빌드와 자동 테스트 실행은 사용자의 로컬에서 확인 필요
