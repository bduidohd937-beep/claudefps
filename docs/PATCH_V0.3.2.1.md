# FPS V0.3.2.1 — Spawn System V5 / Fair Duel

## 구현
- 플레이어와 AI의 스폰을 **개별 난수 좌표가 아닌 한 쌍**으로 평가한다.
- 기본 지면/천장 충돌, 캡슐 여유, 발밑 5점, 탈출 방향 8점 검사 유지.
- 양쪽 스폰의 이동 여유, 시야 노출, 상대 거리, 고도 차, 실제 NavGraph A* 연결 거리, 반복 스폰 여부를 통합 평가한다.
- NavGraph에서 확인된 경로가 존재하지 않는 스폰은 **미확인**으로 남긴다. 경로가 아직 탐색 중이면 F6에서 대기 상태로 표시하고 그래프가 확장되면 자동 재검사한다.
- 지형 자체가 불안전한 위치는 탐색 대기가 아닌 부적합으로 판정한다.
- 맵 최고점에서만 바닥을 찾던 스폰 검색을 요청 높이 인근에서 찾는 방식으로 바꿔 의도하지 않은 옥상 선택을 줄였다.
- F6: 양쪽 좌표 검사 버튼, 안전도 비교 점수, 탈락 사유, 스폰 거리, 고도 차, 이동 경로 길이, 내비게이션 그래프 탐색 수 표시.
- 물리 검사 값 캐시, 불합격 후보의 A* 계산 생략.
- 안전한 조합이 없다면 기존대로 경기 시작을 보류하고 F6에서 수정할 수 있도록 한다.
- 기본 아레나는 물리·시야 검사를 우선하며 그래프 검사 없이 `부분 검증`으로 구분한다.
- 호환 옵션: 맵이 NavGraph 검사 단계에서 계속 막힐 경우 게임 URL에 `&spawnNav=off` 추가. **AI 경로 탐색은 유지**하지만 스폰의 연결성 검사만 끈다. 이 상태는 F6에 ‘물리 검사만 통과’라고 표시한다.
- 기존 `&nav=off`는 AI 그래프 탐색도 비활성화한다.

## 범위와 한계
- 실제 Ghost City의 모든 건물/층 연결을 보장하는 NavMesh 생성 기능은 아니다.
- NavGraph는 AI 근처에서 점진적으로 샘플링되므로 첫 라운드에서는 F6에서 일시적으로 경로 탐색 대기가 나타날 수 있다.
- 이동 경로가 존재한다고 양측의 전술적 기회까지 100% 균등해지는 것은 아니다. 안전도 점수는 경험적 비교 지표다.
- 테스트는 순수 판정/경로와 빌드를 확인한다. 실제 충돌체·게임 플레이는 사용자 검수 필요.

## 플레이 검수
1. Ghost City: 3~5라운드 스폰이 옥상·막다른 길·시작 직후 상대 시야 노출 위치에 놓이지 않는지.
2. F6: ‘입력된 플레이어·AI 스폰 조합 검사’를 눌러 점수와 사유를 읽는다.
3. 일부러 가까운 위치/고도 차 큰 위치를 지정해 안전 검사에서 거절하는지.
4. 맵 이동 그래프 생성 중이라면 ‘경로 탐색 대기’ 표시가 뜨고, 경로 생성 후 자동 재검사하는지.
5. `spawnNav=off` 비교 시 ‘물리 검사만 통과’로 표시되는지.
6. AI 이동, 5선승, 총기, 발소리, F2 및 F7 정상 유지 여부.
