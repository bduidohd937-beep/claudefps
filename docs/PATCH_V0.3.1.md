# FPS V0.3.1 — AI FOOTSTEPS & FAIR SPAWN (검증 전)

## 사용자가 요청한 문제
- AI가 발소리 없이 다가오므로 플레이어가 위치를 소리로 구분할 수 없음
- AI/플레이어 자동 랜덤 스폰이 공개된 거리 등에 걸려 시작 즉시 죽기 쉬움
- F6 좌표 UI가 두 캐릭터를 한 번에 이동시키고 임의 좌표가 지면 위인지 확인하기 어려움

## 구현한 변경
1. **AI 실제 발소리**
   - 실행(run) 강하고 빠르게, 걷기(walk) 보통, 근거리 조사 중 잠행(crouch) 작고 느리게
   - 플레이어 카메라 기준 좌·우 스테레오 방향, 38m 거리 감쇠
   - 시야가 막히면 0.38배 볼륨 및 저음통과 필터로 약하게 들림
   - AI 사망, 정지, 공중, 구매 및 일시정지 중 발소리 생성하지 않음
   - 별도 MP3 없어도 Web Audio 합성음 작동
   - **주의:** 실제 AI 무릎 굽히기/엎드리기 모션은 미구현. 잠행 속도와 소리만 구현

2. **F6 편집기 독립성**
   - 플레이어/AI 각각 현재 좌표·가까운 지면 맞춤·안전 랜덤 이동·좌표 미리보기·저장
   - 다른 쪽은 이동시키지 않음
   - 랜덤 미리보기는 저장 전까지 스폰 기준점에 반영되지 않음
   - 저장 전 바닥, 경사, 머리 공간, 벽·상대 거리 검증
   - 두 스폰 모두 초기화 가능
   - 다양한 층을 이동하는 NavMesh 구축이나 전체 맵 탐색은 미구현

3. **노출 스폰 방지**
   - 원래 64개 후보를 96개로 확대
   - 상대와 26m 이내 직접 시야가 열리는 랜덤 위치 **거절** (기존 단순 점수 패널티 제거)
   - 큰 맵(가로세로 짧은 쪽 >25m)에서 상대와 40m 이내라면 5.5m 이내의 가까운 엄폐물 없는 랜덤 위치 거절
   - 이전 스폰·상대와 거리·엄폐물 접근성을 기준으로 상위 후보 랜덤 선택
   - 너무 엄격해 후보가 없으면 기존 안전 기준점으로 대체
   - 새 라운드 2.5초간 양쪽 모두 이동 가능, 사격/피해 차단. 화면에 타이머 표시

4. **회귀 테스트**
   - AI 발소리 볼륨 순서/방향/거리 감쇠
   - 스폰 노출/엄폐 필터
   - 기존 FPS 테스트 포함 `npm test`에 신규 4개 추가

## 검증 한계
- 소스 변경·정적 연결은 확인되었으나 테스트 실행과 실제 브라우저 플레이는 미검증
- 업로드 동영상은 실행 환경의 파일 리더 오류로 프레임별 분석이 불가
- NavMesh 또는 플레이 가능한 모든 층 연결성은 미구현
- 맵별 정상 랜덤 스폰과 5선승 매치는 로컬 플레이로 확인 필요
