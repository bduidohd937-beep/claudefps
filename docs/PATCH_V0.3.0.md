# FPS V0.3.0 — MAP TRAVERSAL & AI AWARENESS (검증 전)

## 이번에 코드로 반영된 것
- 외부 GLB 선택 시 전체 Physics 월드가 실제 맵 로딩 완료 이후에 생성되도록 outer Suspense에 위임
- 플레이어: Space+W로 충돌체에서 확인한 약 0.23~0.88m 높이의 낮은 턱 넘기
  - 낮은 전방 장애물, 상체 경로, 착지 지면 기울기, 머리 공간 확인
  - 높거나 안전하지 않은 벽은 넘지 않음
- 플레이어 걸음/달리기/앉은 이동 및 발사 시 소리 위치 이벤트 발행
- AI: 실제 시야가 열릴 때만 사격, 마지막 목격/청각 추정 위치 수색
  - 청각은 거리 기반이며 추정 오차를 포함해 정확한 플레이어 좌표를 알 수 없음
  - 기억이 만료되면 동일 높이·충돌 지면이 있는 곳으로 짧게 순찰
  - 1초 이상 벽의 같은 측면을 따라 이동해 좌우 진동 감소
  - 낮은 단차는 충돌 바닥과 상부 여유가 확인될 때 점프
  - 안전한 바닥이 없는 엄폐 위치는 제외
- 라운드별 랜덤 스폰: 대형 맵 반경 22m까지 후보 확장, 64개 후보 검사
  - 플레이어/AI 거리, 이전 위치와의 차이, 단거리 즉시 노출을 점수화
  - 후보가 없으면 기존의 안전 스폰으로 폴백
- AI 판단 순수 함수 회귀 테스트 3개 추가

## 이번 패치에서 미구현한 것
- 서로 다른 층·건물 사이 계단을 찾아 올라가는 완전한 navmesh/A* 경로 탐색
- 높은 난간·사다리·복잡한 점프 경로에 대한 완전한 경로 설계
- Map GLB별 지면/충돌/네비게이션 수동 검수와 스폰 포인트 풀 데이터 구축
- Ghost City 및 FPS Map의 플레이어·AI가 실제 모든 층에 접근 가능하다는 검증
- 실제 플레이 영상 프레임 분석 (현재 첨부 영상 도구 읽기 실패)

## 로컬 검증 순서
1. `npm test` 후 `npm run build` 통과 여부
2. Ghost City: 1라운드 시작 시 지면 위 생성, 매 라운드 다른 지점에서 스폰되는지
3. 낮은 턱에 W + Space로 접근해서 오르기 / 높은 벽은 넘어가지 않는지
4. AI 시야에서 벗어남 → 마지막 위치 탐색 / 발사 소리 → 해당 지역 조사
5. 골목 및 엄폐물 근처 AI가 벽에 10초 이상 끼이지 않는지
6. 기존 5선승, 구매/사망/장전/조준선 및 총기 조정 기능 회귀 검증

## 설계 원칙
이 패치는 지형 활용을 위한 1차 보강이다. 한 맵에서의 검증 없이
범용 고급 네비게이션이 완성됐다고 표시하지 않는다.
