# claudefps

Vite + React Three Fiber + drei + rapier 기반 1:1 대전 FPS (AI 봇, 5라운드 선승제).

## 실행

```powershell
npm install
npm run dev
```

http://localhost:5173 에서 AI 난이도(1~5)를 고르고 "매치 시작".
맵은 `?map=pvp`로 포함된 PVP GLB 맵을 선택할 수 있습니다. 파일이 없는 다른 맵은 내장 아레나로 대체됩니다.
사격 연습만 하려면 `?training=1` (상점/라운드 없이 더미 사격).

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 (기본 걷기) |
| Shift | 달리기 (탄 퍼짐 큼) |
| C | 앉기 (탄 퍼짐 절반) |
| Space | 점프 |
| 좌클릭 | 사격 / 나이프 |
| R | 재장전 (탄창이 0이 되면 자동) |
| 1 / 2 / 3 | 주무기 / 권총 / 나이프 |
| B | 상점 (열려 있는 동안 게임 정지) |
| Esc | 일시정지 (봇도 멈춤) |
| H | 피격 연출 테스트 |
| F4 / F3 | 지금 위치를 플레이어 스폰 / 봇 스폰으로 저장 (맵별 기억) |
| F2 | 총기 뷰모델 튜너 (아래 참고) |

## 규칙

- 시작 $800 / 킬 +$300 / 라운드 승리 +$3250 / 패배 +$1400 (최대 $16000)
- 라운드마다 구매 15초 → 교전 90초 (시간 초과 시 AI 승리). 먼저 5승하면 매치 종료.
- 라운드 종료 3초 후 위치 초기화. 생존하면 장비 유지, 사망하면 주무기·아머를 잃고 돈은 유지.
- 아머: 피격 데미지의 66%를 아머가 먼저 흡수하고 나머지 34%만 HP 차감.
- 상점: 하프 아머 $650 (+25), 풀 아머 $1000 (+50), AKS-74u $2500, Glock (기본 지급), 탄약 보충 $100

## AI 난이도

| 레벨 | 반응 | 명중/정밀도 | 행동 |
|---|---|---|---|
| 1~2 | 1.0초 | 낮음 (오차 7°/5°), 데미지 8/10 | 이동하며 사격 |
| 3 | 0.4초 | 보통 (3°), 데미지 13 | 이동 사격 + 체력 낮으면 엄폐 |
| 4 | 0.2초 | 높음 (1.6°), 헤드 조준 50% | 멈춰서 쏘는 브레이킹 + 엄폐 |
| 5 | 0.2초 | 매우 높음 (0.9°), 헤드 조준 70% | 위와 동일, 더 빠른 연사 |

튜닝은 `src/game/Bot.jsx` 의 `DIFF` 표에서 합니다.

## 맵 스폰 위치

GLB 맵은 크기가 제각각이라 스폰이 어색할 수 있습니다. 게임 중 원하는 자리에 서서 **F4**(내 스폰) / **F3**(봇 스폰)을 누르면
그 맵 전용으로 저장되고, 다음 라운드부터 적용됩니다. 좌하단 디버그 텍스트에 현재 좌표가 표시됩니다.
라운드 시작 시에는 저장 좌표 주변의 바닥·벽·천장을 검사해 캡슐이 들어갈 수 있는 가장 가까운 안전 지점으로 자동 보정합니다.

## 총기 모델 위치/방향 맞추기 (F2 튜너)

총기 GLB는 제작자마다 원점과 방향이 달라서, 어색하게 보이면 게임 중 **F2**를 눌러 튜너를 켜고 조정하세요.
(J/L 좌우, I/K 상하, U/O 앞뒤, Z/X 크기, N/M 좌우 회전, T/G 위아래 회전, Backspace 초기화)
값은 브라우저에 자동 저장되고 콘솔에 `[vm tune]` 으로 출력됩니다. 확정되면 그 값을 `src/game/ViewModels.jsx` 의 `VM`에 반영하면 됩니다.

## GLB 최적화 / 큰 파일

```powershell
npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 2048
```
파일 하나가 100MB를 넘으면 GitHub 푸시가 막히니 Git LFS(`git lfs track "*.glb"`)를 쓰세요.
